# 实训基地路线图（招聘侧）

招聘视角：实训基地在招聘中的角色。公司级全景见 quanttide-org intention 仓库的 `training-base.md`（domains/quanttide-org/data/intention/）（双路径枢纽——本文件只讲招聘路径）。

招聘已并入课堂体系：实训基地是招聘的承载。招聘解决人才培养问题，高度情境化、与公司绑定；教学更通用朴实，两者管理上分开、内部统一标准。

## 招聘路径（路径 B：招聘 → 课堂）★侧重

- **投递 → 邀请加入实训基地（进群即开始）**——无前置筛选步骤，筛选全部发生在选题制考核内部
- **选题制考核**：自主发现问题 → 课题申请 → 逐轮点评迭代 → 实际产出验收（固定笔试题已淘汰——"考核不会以固定题目为主"）
  - 课题立项评审依《量潮招聘考核课题立项评审章程》执行（联盟章仓 `docs/bylaw/qtrecurit/proposal.md`）：方向偏好轴（质量控制导向）与陈述质量轴（可验证验收）双轴独立评审
- **直通考核**：表现突出者可跳过实训直接参与招聘考核（通过 ≠ 一定入职，无岗则长期实训/保留合作）
- **逆向导流**：通过后转课堂体系（无合适岗位 → 长期实训/转正式学员）

## 招聘侧阶段目标

1. 选题制考核承接招聘筛选（实际产出代替答卷）
2. 轨道政策落地（实习转实训、实训专门招募，统一安排到实训基地）
